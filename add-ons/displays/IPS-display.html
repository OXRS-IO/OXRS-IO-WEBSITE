# 1.54″ 240×240 IPS

IPS Display

This is the IPS display commonly used with the Rack32 controller via the 8 pin IDC (SPI) header. While there is a slightly smaller version of this display, this one was choosen because it has the CS connection, which is required in our use case.

Most OXRS firmware has some form of support for this display, showing firmware and network/MQTT connection details, along with some form of I/O state depending on the firmware type.
